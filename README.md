## 🧠 Algorithm & Environment

| | |
|---|---|
| **Algorithm** | Tabular **Q-Learning** — off-policy, epsilon-greedy exploration |
| **Environment** | `FrozenLake-v1` (Gymnasium), 4×4 map, `is_slippery=True` |
| **State space** | `Discrete(16)` — one integer per grid tile |
| **Action space** | `Discrete(4)` — Left, Down, Right, Up |
| **Why this environment?** | Small enough that the *entire* Q-table can be inspected and understood directly — no black-box behaviour. Full justification in [`GYMNASIUM.md`](GYMNASIUM.md). |

**The Q-Learning update rule** used in [`rl/agent.py`](rl/agent.py):

Q(s, a) ← Q(s, a) + α [ r + γ · maxₐ' Q(s', a') − Q(s, a) ]


- `α` (alpha) — learning rate: how much each update shifts a Q-value
- `γ` (gamma) — discount factor: how much future reward matters
- Epsilon-greedy: mostly exploits the best-known action, occasionally
  explores randomly with probability `ε`, which decays over training

## ⚙️ Hyperparameters

All defined in one place — [`config.py`](config.py):

| Hyperparameter | Value | Purpose |
|---|---|---|
| Learning rate (`α`) | `0.1` | How much each update shifts a Q-value |
| Discount factor (`γ`) | `0.99` | Weight given to future rewards |
| Epsilon start / min / decay | `1.0 / 0.01 / 0.9995` | Exploration schedule (per episode) |
| Training episodes | `15,000` | Number of training runs through the environment |
| Evaluation episodes | `1,000` | Greedy-policy test runs after training |
| Max steps per episode | `100` | Truncation limit per episode |
| Random seed | `42` | Full reproducibility of results |

## ♟️ Game Theory Case Study

**Scenario (Part 5E):** two cooperating components of a RAG pipeline — a
**Retriever Agent** and a **Generation Agent** — each deciding whether to
reuse a cached result (cheap) or make a fresh API call (costly), while
sharing one cost budget.

**Payoff matrix** (payoffs are costs — less negative is better):

| Agent A \ Agent B | Use Cache | Call API |
|---|---|---|
| **Use Cache** | (−1, −1) | (−1, −5) |
| **Call API** | (−5, −1) | (−5, −5) |

Run `python game_theory/payoff_matrix.py` to reproduce:

Pure-strategy Nash Equilibria:
A: Use Cache, B: Use Cache -> payoffs (-1, -1)


🏆 **Result:** `(Use Cache, Use Cache)` is the only Nash Equilibrium — and
unlike the classic Prisoner's Dilemma, it's *also* the jointly optimal
outcome. Self-interested agents naturally converge on the cost-minimising,
cooperative strategy without needing a binding agreement.

## 🔬 How It Works — Code Walkthrough

```python
# rl/agent.py — the core Q-Learning update
def update(self, state, action, reward, next_state, done):
    best_next = np.max(self.q_table[next_state]) if not done else 0.0
    td_target = reward + self.gamma * best_next
    td_error = td_target - self.q_table[state, action]
    self.q_table[state, action] += self.alpha * td_error
```

```python
# rl/train.py — the training loop, per episode
state, _ = env.reset()
for step in range(config.MAX_STEPS_PER_EPISODE):
    action = agent.select_action(state)                 # epsilon-greedy
    next_state, reward, terminated, truncated, _ = env.step(action)
    agent.update(state, action, reward, next_state, terminated or truncated)
    state = next_state
    if terminated or truncated:
        break
agent.decay_epsilon()                                     # once per episode
```

```python
# rl/evaluate.py — testing the trained policy (no exploration)
action = agent.select_action(state, greedy=True)
```

See [`GYMNASIUM.md`](GYMNASIUM.md) for a full breakdown of the Gymnasium
API (`reset()`, `step()`, observation/action spaces) used above.

|---|---|
